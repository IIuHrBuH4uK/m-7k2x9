# Сайт-приглашение на свидание 💗

Маленький статичный сайт-приглашение: милые сообщения, приглашение на свидание,
выбор заведения и дня, а ответ приходит вам в Google Таблицу и на почту.

Хостинг — GitHub Pages, сборка не нужна: чистые HTML/CSS/JS.

---

## Как это устроено

```
index.html                 экраны и разметка
styles.css                 розовая тема, анимации, мобильная вёрстка
app.js                     логика: сообщения, кнопка «Нет», выбор, отправка
schedule.js                расчёт свободных дней по графику 2/2
config.js                  настройки (имя, URL приёмника, график, время)
robots.txt                 запрет индексации
google-apps-script/Code.gs приёмник ответов: таблица + письмо
```

Ответ уходит `POST`-запросом в веб-приложение Google Apps Script.
Скрипт пишет строку в таблицу и отправляет письмо.

## 1. Локальный запуск

В папке проекта:

```powershell
npx serve -l 4173
# или, если установлен Python:
python -m http.server 4173
```

Открыть <http://localhost:4173>.

Сейчас в `config.js` стоит `testMode: true` — сайт работает полностью, но ответ
не отправляется, а печатается в консоль браузера (F12 → Console). Это удобно для проверки.

## 2. Google Таблица и письмо

1. Создайте новую таблицу на <https://sheets.google.com> (название любое).
2. В таблице: **Расширения → Apps Script**.
3. Удалите заготовку и вставьте содержимое файла `google-apps-script/Code.gs`.
4. В начале скрипта проверьте:
   - `SECRET` — должен совпадать с `secret` в `config.js` (по умолчанию уже совпадает);
   - `NOTIFY_EMAIL = 'ваша_почта@gmail.com'` — куда присылать письмо.

   > В публичном репозитории оставляйте `NOTIFY_EMAIL` пустым и указывайте адрес
   > только в редакторе Apps Script — иначе почта попадёт в открытый доступ.
5. Сохраните (Ctrl+S).
6. **Развернуть → Новое развёртывание → тип «Веб-приложение»**:
   - Описание: `milena`;
   - Запуск от имени: **Я**;
   - У кого есть доступ: **Все**;
   - Нажмите «Развернуть» и разрешите доступ (появится окно Google).
7. Скопируйте URL веб-приложения — он заканчивается на `/exec`.
8. Вставьте его в `config.js`:
AKfycbwdLAvOSGN1xqiL3sdb4HXbWyZFtqDOvLq_OeJ9A2sOzXgVRsQagUbpB923CVir-UUcVQ
https://script.google.com/macros/s/AKfycbwdLAvOSGN1xqiL3sdb4HXbWyZFtqDOvLq_OeJ9A2sOzXgVRsQagUbpB923CVir-UUcVQ/exec
```js
sendUrl: 'https://script.google.com/macros/s/AKfycb.../exec',
testMode: false,
```

9. Быстрая проверка (PowerShell, подставьте свой URL):

```powershell
curl.exe -sS -L -H "Content-Type: text/plain;charset=utf-8" `
  --data '{"secret":"milena-7f3a91c2e5","venue":"Проверка","date":"2026-11-01","dateLabel":"Тест","time":"19:00"}' `
  "https://script.google.com/macros/s/ВАШ_ID/exec"
```

Должно появиться `{"ok":true}`, новая строка в таблице и письмо.

> Если меняли код скрипта после развёртывания — создайте новую версию:
> «Развернуть → Управление развёртываниями → карандаш → Версия: новая».

## 3. Публикация на GitHub Pages

1. Создайте публичный репозиторий `milena`.
2. Загрузите все файлы проекта в ветку `main` (кроме служебных папок).
3. **Settings → Pages → Build and deployment**:
   - Source: `Deploy from a branch`;
   - Branch: `main`, папка `/ (root)`;
   - Save.
4. Через 1–2 минуты сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/milena/
```

Ссылка не индексируется (`noindex` + `robots.txt`), но технически страница публичная —
не публикуйте её в открытых местах и не вставляйте в профили.

## 4. Что легко поменять

| Что | Где |
|---|---|
| Имя девушки | `config.js` → `name` |
| Тексты сообщений | `app.js` → массив `MESSAGES` |
| Заведения и подписи | `app.js` → массив `VENUES` |
| График 2/2 | `config.js` → `schedule.anchorDate`, `workDays`, `offDays` |
| Дни недели для свиданий | `config.js` → `weekdays` (5 — пятница, 6 — суббота) |
| Слоты времени | `config.js` → `times` |
| Цвета | `styles.css` → блок `:root` |
| Количество вариантов дат | `config.js` → `count` |

После правок — коммит и пуш, GitHub Pages обновится за минуту.

## 5. Если что-то не работает

**Ответ не приходит в таблицу**
- `testMode` всё ещё `true` или пустой `sendUrl` в `config.js`;
- у веб-приложения доступ не «Все»;
- после правки скрипта не создана новая версия развёртывания;
- откройте URL `/exec` в браузере — должен вернуться `{"ok":true,...}`;
- посмотрите «Выполнения» в Apps Script — там будет ошибка.

**Письмо не пришло**
- не заполнен `NOTIFY_EMAIL`, письмо ушло на почту владельца скрипта;
- проверьте «Спам»;
- у бесплатного Gmail есть суточный лимит писем, но для одного ответа это не проблема.

**Сайт открылся, но кнопки не работают**
- откройте консоль браузера (F12), скорее всего ошибка в `config.js`
  (например, лишняя запятая или кавычка).

**Хочу пройти тест заново**
- в браузере: F12 → Application → Local Storage → удалить ключ `milena-date-answer-v1`
  (или откройте сайт в приватном окне).

## Приватность

Сайт не использует аналитику, куки и сторонние трекеры. Наружу уходит только
выбранное заведение, дата, время и случайный ID ответа. Имя девушки хранится
в коде страницы.

Котик нарисован специально для этого сайта в kawaii-стиле: точные персонажи
Hello Kitty принадлежат Sanrio, поэтому используется собственный похожий персонаж.
